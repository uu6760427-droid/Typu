
Универсальный клиент для управления VPN-подписками, поддерживающий протоколы V2Ray, Clash, Shadowsocks, WireGuard и другие на основе единого ядра Sing-box.

Описание:
 Combine — это приложение для Android, разработанное на Flutter, которое объединяет функциональность популярных менеджеров подписок (таких как Karing, Happ, V2RayNG) в одном интерфейсе. Оно позволяет подключать внешние конфигурации, автоматически конвертировать их во внутренний формат и управлять подключением через единый переключатель.

Особенности

· Поддержка всех основных протоколов: VMess, VLESS, Trojan, Shadowsocks, Hysteria2, TUIC, WireGuard.
· Интеллектуальный парсинг ссылок и файлов подписок (Clash, Sing-box, обычные URI).
· Автоматическое обновление подписок по расписанию.
· Умный роутинг на основе встроенных GeoIP/GeoSite баз.
· Отображение скорости соединения и статистики трафика в реальном времени.
· Тёмная и светлая тема с сохранением выбора.
· Анимации интерфейса для плавного взаимодействия.
· Поддержка нескольких серверов с переключением одним касанием.

Требования

· Android 5.0 (API 21) и выше.
· Доступ в интернет для получения подписок.
· Установленный пакет подписок (ссылку или файл вы предоставляете сами).
